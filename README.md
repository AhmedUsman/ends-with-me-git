# EndsWithMe.com — GitHub Pages package

The website files are unchanged from the approved preview. This package is ready for GitHub Pages; no Netlify account or build command is needed.

## Publish

1. On GitHub, create a **public** repository, for example `endswithme`.
2. Extract this ZIP on your computer. Upload the extracted **contents** to the repository root, so `index.html`, `.nojekyll`, and `assets/` are directly visible in the repository. Do not upload only the ZIP file or place everything inside a nested folder.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose **main** and **/(root)**, then **Save**.
4. GitHub will show the website address in **Settings → Pages** when publication finishes. For a repository named `endswithme`, it will have the form `https://YOUR-USERNAME.github.io/endswithme/`.

The URL is shareable. The Pages website is public. If you want only selected reviewers to see an unpublished version, share the existing private preview instead.

## Later

The sign-up button still displays a “form being connected” message. It collects no information. Add your form URL before inviting visitors to sign up.

You can connect `endswithme.com` later through GitHub Pages custom-domain settings and your DNS provider. The GitHub Pages address works without connecting the domain.
